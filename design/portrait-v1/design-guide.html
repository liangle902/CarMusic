音乐是主角，操作有固定的位置。

星河音乐 / 竖屏自适应。采用深石墨色的座舱底色，以专辑封面、清楚的歌词和稳定的播放控制建立视觉层次。

这是静态 HTML 设计包，不是 Android 实现。所有歌曲、歌词、账号、歌单、容量与任务记录均为虚构示例。演示状态仅存在于当前页面内存，刷新后重置；不进行真实播放、登录、下载、同步或文件删除。

首页正在播放歌单列表我的收藏系统设置状态设计

已经确定的产品规则

  • 每次启动默认进入四模块首页。
  • 启动后自动播放默认关闭，用户可在设置手动开启。开启后仍进入首页，只恢复播放；关闭时保留队列与进度，等待点击播放。
  • 歌单列表以歌单为主，我的收藏以歌曲为主。两个入口可访问相同内容，但服务不同的任务。
  • 播放页默认专辑封面，保留黑胶选项。点击封面或歌词展开歌词，再返回封面。
  • 播放队列独立于真实歌单、收藏和本地文件。排序与移出队列不改动它们。
  • 红心默认收藏到 APP；不假设关联平台后支持双向同步。

开屏与品牌

星轨与音符组成原创矢量标志。开屏覆盖整个窗口，包括侧边栏；结束或跳过后恢复原页面。正常联网不显示常驻在线标记，异常时在对应页面提供提示与重试。开屏以流动星轨和描边文字呈现“一路星河，一路好歌。”，保留原句“为每一段旅程，留一首好歌。”；支持跳过与重播，减少动态效果时立即展示静态文字。关于页面以 GoMusicDll 标示功能来源，保留 Go Music DL 的介绍及原始项目链接；星河音乐尚未建立仓库，项目链接留空。

视频素材编辑

视频制作用于将音频、封面和歌词合成为视频，作为上游兼容功能保留在高级选项，不出现在主菜单。界面不展示无法获取的气温。主题可跟随系统；已收藏歌曲使用实心红心。

在高级选项开启更换封面/背景、更换音频、更换歌词与导出视频按钮后，从视频制作页面进入对应面板。封面可选内置素材或本地图片；背景支持跟随封面、纯色和独立图片；音频可选歌曲或本地文件，确认后更新预览。导出仅演示选项，不生成实际视频。

1440 × 1920 的布局策略

应用区域（扣除系统安全区后） 顶部：状态与标题 中上部：封面与歌词并排 / 歌单与歌曲浏览 中下部：固定顺序的主播放控制 底部：播放页使用队列按钮；浏览页使用迷你播放器 最下方：正在播放 / 歌单列表 / 我的收藏 / 设置

预览按竖屏窗口自适应，可收起侧边栏或铺满窗口。布局比例不等于实车 dp 或字号。尚未确认系统导航、车控栏、安全区和全屏行为，原生实现必须用实际可用宽高测量布局。

手机预览只用于远程查看稿件；目标是车机竖屏。移动宽度下部分内容可滚动，迷你播放器保留在框架内，页面统一从侧边栏进入。网页使用 reduced-motion、焦点轮廓、按钮标签和弹窗焦点约束。

队列、收藏与文件的区别

操作结果用户反馈
移出队列只移除队列引用，不删除歌单、收藏或文件短暂撤销；当前曲移除后播放下一首
取消 APP 收藏只修改 APP 收藏，不写入平台红心状态变化与文字反馈

下一首播放插入当前曲之后提示已设为下一首
加入队列追加至末尾提示加入成功
随机播放打乱队列，再按可见顺序播放显示实际顺序，拖动后按新顺序播放

开发 Agent 的交接边界

  • 以 HTML 为视觉和交互参考，用 Compose 原生实现；不要把整套页面替换成 WebView 产品。
  • 先冻结上游版本并做功能逐项审计。此设计覆盖主要流程，不等于已经验证所有平台、视频功能和 Android 系统设置。
  • 平台个人歌单需要区分“我创建的”和“我收藏的”；本稿提供全部、我创建的、我收藏的三个分组示意；原生版必须读取真实归属。
  • 我的收藏优先展示平台喜欢的歌曲；不支持时提供收藏歌单入口，不能把歌单与喜欢歌曲误当成同一资源。
  • 需要真实实现：Media3 播放、后台与方向盘控制、音频焦点、网络重试、下载/缓存区分、数据库持久化、账号安全与平台能力检测。
  • 启动自动播放关闭的默认值必须在真实配置层落实。演示开关不控制网页真实音频，也不跨刷新保存。
  • 实车验证大字、热区、触达范围、系统底栏遮挡、日夜对比和导航打断。不能仅凭分辨率计算出最终字号。
  • 账号绑定、Cookie、视频生成和文件管理属于低频长操作。设计阶段保留能力；车机使用状态限制需要真实车况接口确认，不能假设能可靠读取车速。
