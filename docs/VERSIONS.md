# 版本路线

| 版本 | 内容 | 发布条件 |
| --- | --- | --- |
| v1.0.0 | 竖屏界面、平台搜索与歌单、播放与歌词、队列排序、本地扫描、下载与系统配置 | 正式签名，APK 与源码同步交付 |
| v1.5.0 | 横屏车机与手机横屏自适应，复用当前播放、账号、歌单和存储逻辑 | 横竖屏切换及各页面正常工作 |
| v1.5.1 | 车机界面放大、媒体键补全、搜索音源记忆与页面返回、换源超时保护 | 手机回归通过 |
| v1.6.0 | 吉利 oneOS 车机方向盘按键控制、弹窗随界面放大、迷你播放条重做、播放页歌手搜索 | 博越 L 实车验证通过 |
| v2.0.0 | 车机全功能版本：导航语音避让、按键监听与播放状态同步、音频焦点恢复 | 完成实际车机上的协同验证后发布 |

正式发布统一使用产品名称和版本号，不在界面或附件名称中附加阶段性标识。
