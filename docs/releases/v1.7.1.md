# 星河音乐 v1.7.1

让好音乐，随心而听。

- 先播后升：第一个能播放的版本一返回就开始播放；其余音源返回后，如果有明显更高的码率，会在当前进度上自动换过去。切换瞬间可能有很短的停顿。
- 全音源解析：播放时并行向所有音源解析，在能播放的版本里选码率最高的。开始播放后会预先解析队列里的下一首，切歌更快。
- 解析失败不再打扰：单个音源失败时静默换到下一个可用的版本，所有音源都不可用才提示并跳到下一首。
- 点击码率切换：播放页歌名后的码率可以点击，列出这首歌可用的各档码率，点选即切换并保留进度。手动选择会被记住。
- 搜索默认使用全部音源，之后的选择仍会被记住。
- 播放页去掉了歌手下方的音源与换源状态一行。

覆盖安装可保留当前数据。之前记住的搜索音源选择会重置为全选。
