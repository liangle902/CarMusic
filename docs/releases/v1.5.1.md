# 星河音乐 v1.5.1

让好音乐，随心而听。

- 大屏与车机：屏幕短边不小于 600dp 时按手机设计尺寸整体等比放大，解决车机上字体和控件过小。
- 媒体键：补充单独的播放、暂停、停止、跳转键，应用在前台时也由 Activity 兜底转发，方向盘按键可切歌和暂停。
- 全网搜索：音源选择会被记住；切到其他页面再返回，搜索结果和歌单详情保留。
- 正在播放页返回时回到进入前的页面。
- 平台账号：未关联时不再显示“解除关联”。
- 换源与播放：自动换源、音源检测增加超时，缓冲超过 25 秒按失败处理并自动换源或跳到下一首，避免队列停住。

覆盖安装可保留当前数据。方向盘按键与车机放大比例的实车验证仍在进行。
