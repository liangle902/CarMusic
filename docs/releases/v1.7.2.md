# 星河音乐 v1.7.2

让好音乐，随心而听。

修复 v1.7.1 自动升级码率时会换成同名翻唱的问题。

- 更严格的版本匹配：换到别的音源前，要求歌名一致、至少有一位歌手相同、现场/Remix/伴奏等版本标记一致、时长相差不超过 5 秒。只有满足这些条件的版本才会用于自动升级码率，也才会出现在码率列表里。
- 兜底播放：原音源无法播放、又没有完全一致的版本时，退到同名且歌手相同的版本，不会再换成歌手不同的翻唱，也不会直接跳过。
- 清理旧记录：v1.7.1 记住的不一致版本会在下次播放时自动清除并重新解析。
- 手动选择优先：在码率列表里手动选定的版本不会再被自动升级覆盖。自动记住的版本只作为下次的起播版本，之后仍会寻找更高码率。
- 已缓存的低码率版本起播后，同样会在后台寻找更高码率并升级。

覆盖安装可保留当前数据。
