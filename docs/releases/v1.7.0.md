# 星河音乐 v1.7.0

让好音乐，随心而听。

这一版把星河音乐真正接进了车机：方向盘能控制，导航和语音助手说话时音乐会自动让路。

- 语音避让：导航播报、语音助手应答、通话和来电铃声响起时，音乐自动压低，对方说完后恢复。按键音和普通通知音不会触发。使用安卓标准接口，手机和其他车机同样适用。
- 方向盘按键：吉利 oneOS 车机（博越 L 实车验证）上，方向盘的播放/暂停、上一首、下一首可直接控制星河音乐。暂停后再按会恢复星河音乐，退出应用后按键交还车机自带音源。
- 车机界面：弹窗、音源选择和播放队列随界面一起放大，不再是小窗口。
- 迷你播放条：新增封面、当前歌词和播放进度，按钮加大，可直接打开播放队列。
- 歌手搜索：在播放页点击歌手名，直接搜索该歌手的歌曲；多位歌手可分别点击。

覆盖安装可保留当前数据。车机通知栏显示仍有问题，后续版本处理。
