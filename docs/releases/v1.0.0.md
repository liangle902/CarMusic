# 星河音乐 v1.0.0 · 竖屏验收版

此版本作为横屏开发之前的竖屏基线，以开发验收版发布。

## 本次更新

- 长歌名单行从右向左滚动，应用于首页、播放页、歌曲列表、队列和迷你播放器。
- 播放队列右侧三横杠支持跟手拖动和实时换序；删除叉与手柄相邻，调整只影响播放队列。
- 本地音乐默认自动扫描系统媒体库，支持添加持久授权音乐目录和 U 盘目录；扫描／导入记录可移除并恢复，保留原文件。
- 保留既有四个功能分区、侧栏、主题、歌词交互、图标播放控制、四种播放模式、通知栏、平台账号、歌单、下载与自动换源功能。

## 验证与设备

Redmi K20 Pro / Android 14 真机增量与相关回归，14 项 Kotlin 单元测试。长歌名滚动、自动扫描、播放、歌词、通知、歌单和换源有通过记录；用户确认队列跟手和向后自动滚动正常。跨批次结果、自动测试超时与限制见[发布验证记录](https://github.com/liangle902/CarMusic/blob/v1.0.0/docs/validation/PORTRAIT_RELEASE_2026-10-03.md)。
