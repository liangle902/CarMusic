# 星河音乐 v1.0.0

让好音乐，随心而听。

## 功能

- 首页、正在播放、歌单列表、我的收藏、系统设置，以及统一侧栏导航。
- 日间、夜间与跟随系统主题，专辑封面／黑胶显示，全屏开场动画。
- 长歌名单行滚动，图标播放控制，顺序／随机／单曲循环／列表循环四种模式。
- 滑动浏览歌词，点击定位播放，2 秒后自动回到当前歌词。
- 队列右侧拖动手柄，实时换序、边缘滚动与移除；歌单播放与单曲播放采用统一队列规则。
- 多平台搜索、账号关联、个人／推荐歌单、收藏、本地歌单与批量下载。
- 本地媒体库自动扫描、持久授权目录与 U 盘支持，扫描引用可移除和恢复。
- 播放自动换源、成功来源记忆、缓存、通知栏媒体控制、下载管理及完整系统配置入口。
- 本机音乐引擎由系统动态分配端口，避免固定端口占用。

## 安装

Android 8.0 / API 26 及以上，ARM64。正式 Release 构建，关闭调试，使用星河音乐签名。

下载附件 `CarMusic-v1.0.0-arm64.apk`。桌面交付文件名为 `星河音乐_CarMusic_v1.0.0.apk`，内容相同。`SHA256SUMS.txt` 提供文件校验值。

功能来源：[GoMusicDll](https://github.com/guohuiyuan/go-music-dl)。保留 GNU AGPL v3 许可证、上游介绍与源码。
