# 星河音乐 v1.5.0

让好音乐，随心而听。

- 横竖屏自动适配，旋转时保留页面、播放进度与队列。
- 横屏首页标题与标语并排，搜索框和来源筛选按可用高度调整。
- 首页、播放、平台歌单、收藏、搜索、本地音乐和系统设置使用统一侧栏。
- 顺序、随机、单曲循环、列表循环；队列手柄拖动排序与移除。
- 歌词滑动浏览，点击跳转进度，停止浏览两秒后回到当前歌词。
- 播放页歌曲标题后显示较小字号的音频码率，未知码率隐藏。
- 搜索框手动清空后恢复初始页面，保留歌曲、歌单与专辑切换入口。
- 动态本机引擎端口、平台扫码关联、换源记忆、下载、缓存与本地音乐扫描。

系统要求 Android 8.0 及以上、ARM64。导航语音避让、车机媒体按键与状态同步的实车验证安排在 v2.0.0。

## 2026-10-04 更新构建

应用版本保持 1.5.0，发布标签使用 `v1.5.0+20261004` 标记此次构建，源码归档与 APK 对应同一发布提交。

- 搜索多选结果可按显示顺序追加到正在播放列表，去重并保留已有播放状态。
- 歌曲、歌单、专辑入口保持可见；手动清空搜索框后恢复初始页面，并丢弃旧请求结果。
- 播放页标题后以较小字号显示音频平均码率，未知值隐藏。
- 改善平台歌单与下载记录请求切换、扫码会话校验、账号保存失败处理和重复加密保存。
- 强化本机引擎认证、凭据存储、备份排除、媒体会话控制、本地索引路径校验与分块下载内存边界。
- 移除已被统一界面替代的旧组件，补充回归检查及 GitHub Actions。

覆盖安装可保留当前数据。Release 单元测试 12 项通过，Android lint 0 错误；相关 Go 回归检查与 ARM64 构建通过。搜索清空和码率显示的真机交互仍需手动核对，实车验证计划保持不变。
