# CarMusic (星河车载音乐) 架构与开发设计方案

## 一、 项目背景与硬件目标
* **项目定位**：专为吉利博越L（银河OS / 8155座舱）及现代车载竖屏大屏打造的开源无损车载音乐播放器。
* **目标硬件规格**：
  * **车型代号**：吉利博越L (`FX11_LOW`)
  * **芯片架构**：高通骁龙 SA8155P（ARM64v8a，Adreno 640 GPU）
  * **系统版本**：Android 11（API Level 30，`ecarx-userdebug`）
  * **屏幕规格**：13.2 英寸纵置高清屏（**1440 × 1920**，Density 160 dpi）
  * **可用存储**：`/data` 分区余量 ~48 GB

---

## 二、 整体架构设计（双层解耦）

采用**“Go 语言引擎后端 + Kotlin/Compose 原生车载前端”**的彻底解耦架构：

```
+---------------------------------------------------------------+
|               【Android 原生前端 (Kotlin / Compose)】          |
|  - 1440x1920 竖屏专属布局 (70% 视听 + 25% 控制板 + 5% 底栏)     |
|  - Apple Music 风格流动光晕 + 逐行卡拉OK歌词系统              |
|  - 唱片/全屏歌词“大小互斥”与左下角退避画中画动效              |
+-------------------------------+-------------------------------+
                                |
                                v
+---------------------------------------------------------------+
|               【车规级服务宿主 (AndroidX Media3)】             |
|  - MediaSessionCompat：100% 拦截并响应方向盘方控切歌/暂停按键  |
|  - AudioFocusManager：高德导航语音、倒车雷达、蓝牙通话平滑避让|
|  - LoudnessCodec：全网音源动态响度归一化 (防爆音)             |
|  - ExoPlayer + CacheDataSource：实现【边听边存】与离线优先    |
+-------------------------------+-------------------------------+
                                | (Local REST API / JNI)
                                v
+---------------------------------------------------------------+
|             【音乐解析与聚合引擎 (Go-Music-DL 内核)】           |
|  - 全网多平台无感聚合搜索 (网易云、QQ音乐、酷狗、B站等)       |
|  - 无损 FLAC/高品质音质解析与歌词/封面抓取                    |
|  - SQLite 本地歌单存储与外部三方歌单导入                     |
+-------------------------------+-------------------------------+
```

## 三、 屏幕交互布局规范 (1440×1920)

### 1. 区域划分
* **70% 沉浸视听区（上部）**：
  * **默认唱片态**：超大 3D 黑胶自转封面，正下方卡拉OK双行大字号歌词（高亮当前句 + 弱化下一句）。
  * **歌词沉浸态**：点击黑胶或歌词后进入，多行大字号滚动歌词；黑胶唱片平滑缩小退至**左下角**，歌词半透明穿透覆盖在唱片上方；点击左下角缩略唱片即可弹回大图。
* **25% 驾驶盲操控制区（中下部）**：
  * 纯透明/半透明磨砂毛玻璃卡片；
  * 超大播放/暂停主键（>96dp 热区）、上一曲、下一曲；
  * 一键红心收藏（加入“我喜欢的音乐”）、播放模式切换（顺序/随机/单曲）；
  * 播放列表抽屉开关（点击从右侧滑出轻量半屏面板，默认关闭）。
* **5% 底部常驻导航条（最底部）**：
  * `[ 🔍 搜索发现 ]`、`[ 📥 我的 (下载/歌单/历史) ]`、`[ ⚙️ 设置 ]`。

## 四、 功能对照清单与边界

| 模块分类 | 具体功能项 | 功能归属 | 技术方案 |
| :--- | :--- | :--- | :--- |
| **音乐解析** | 全网并发聚合搜索 | **100% 复用 MusicDL** | 无需手动选平台，输入即搜全部音源 |
| **音乐解析** | 无损 FLAC / 高品解析 | **100% 复用 MusicDL** | 自动提取最高音质流媒体直链 |
| **元数据** | LRC 歌词与封面抓取 | **100% 复用 MusicDL** | 提取时间戳歌词与高清 Album Art |
| **资产管理** | 本地音乐扫描与管理 | **100% 复用 MusicDL** | SQLite 建立索引，支持 MP3/FLAC/M4A |
| **资产管理** | 外部歌单/专辑导入 | **100% 复用 MusicDL** | 支持网易云/QQ 歌单分享链接或 Cookie 导入 |
| **离线体验** | **边听边下载 (Cache)** | ⭐ **车机专属增强** | ExoPlayer `SimpleCache` 流式写入存储 |
| **离线体验** | **离线优先 (免流量播放)** | ⭐ **车机专属增强** | 命中已下载文件时，100% 走本地无损 |
| **车规体验** | **方向盘方控切歌** | ⭐ **车机必要能力** | 原生 `MediaSessionCompat` 广播响应 |
| **车规体验** | **导航与雷达避让** | ⭐ **车机必要能力** | `AudioManager.requestAudioFocus` 平滑避让 |
| **车规体验** | **点火自动断点续播** | ⭐ **车机必要能力** | 记录 Track ID & Position，开机静默预热 |
| **车规体验** | **动态响度归一化** | ⭐ **车机必要能力** | 音频处理器统一不同音源输出电平 |
| **车规体验** | **随车大灯日夜切换** | ⭐ **车机必要能力** | 随系统暗黑模式联动高对比/防眩光主题 |

## 五、 工程目录规划

```text
CarMusic/
├── app/                              # Android 原生车载应用
│   ├── src/main/java/com/carmusic/
│   │   ├── core/                     # 播放器核心、MediaSession、AudioFocus
│   │   ├── engine/                   # Go 内核桥接层 (Daemon 启动与本地 REST 客户端)
│   │   ├── ui/                       # Jetpack Compose 车载 UI
│   │   │   ├── nowplaying/           # 70% 视听区 (黑胶唱片、卡拉OK歌词互斥)
│   │   │   ├── controls/             # 25% 盲操控制面板
│   │   │   ├── navigation/           # 5% 底部导航栏与抽屉
│   │   │   └── theme/                # 车载深色/日夜模式与 Apple Music 流光色彩引擎
│   │   └── data/                     # 歌曲、歌单、缓存数据库与设置
│   └── build.gradle.kts
├── engine/                           # Go 核心模块 (基于 go-music-dl)
│   ├── headless/                     # 去除 Gio/Web 视图的纯净后台服务
│   └── build_arm64.sh                # SA8155P ARM64 交叉编译脚本
└── docs/                             # 架构与设计规范文档
```

## 六、 分步实施里程碑 (Milestones)

1. **里程碑 1 (内核验证)**：将 `go-music-dl` 抽离为纯净的无头轻量后台服务，编译并在测试机/车机（ARM64）上验证 REST API 畅通；
2. **里程碑 2 (工程骨架)**：初始化原生 Android 项目，集成 AndroidX Media3，跑通音频播放与 `MediaSession`（方向盘/耳机按键切歌）；
3. **里程碑 3 (核心 UI 构建)**：用 Compose 实现 1440×1920 竖屏布局，完成黑胶唱片与全屏歌词的“大小互斥”切换动效；
4. **里程碑 4 (体验闭环)**：加入边听边存、导航避让、开机自动续播、响度平齐；
5. **里程碑 5 (车机实车调试与打包)**：安装到真车进行实车路测、调优与打包。
