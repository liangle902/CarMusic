# 歌名滚动、队列拖动、本地自动扫描

本轮完成开发后，已按用户要求执行真机交互与回归，OCR 暂缓。长歌名滚动、队列跟手重排和手机媒体库扫描已有真机证据；用户手测确认队列正常，能够自动向后滚动。真实 U 盘与实车兼容性尚未验证。详见 [发布验证记录](validation/PORTRAIT_RELEASE_2026-10-03.md)。

## 歌名

新增共用 `SongTitle` 组件，标题固定一行、不换行，超出容器后由 Compose `basicMarquee` 从右向左滚动。首次停留 1.2 秒、每轮停留 1.5 秒，速度 28 dp/秒；短标题静止。用于首页、播放页、歌单/收藏/搜索/本地列表、最近听过、迷你播放器、播放队列、下载记录与换源弹窗。拖动中的队列标题暂停跑马灯。

## 播放队列

右侧删除叉旁放置三横杠手柄，按住直接拖动。使用 Reorderable 2.2.0 的已发布组件，拖动行跟随手指、其他行实时让位，接近列表边缘时自动滚动，松手后回落。显示实时序号和正在播放状态；提供读屏的上移/下移操作，没有增加可见箭头按钮。

调整使用歌曲稳定 key 对照实时队列，复用服务的 `moveQueue` 和队列持久化。只修改当前播放顺序，不修改原始歌单。既有播放模式、单曲点击、队列移除和清空规则保留。

## 自动扫描

- 默认启用，设置入口为“系统设置 → 下载与存储 → 自动扫描本地音乐与U盘”。
- 首次开屏结束申请音频读取权限：Android 13+ 使用 `READ_MEDIA_AUDIO`；Android 8–12 使用 `READ_EXTERNAL_STORAGE`。拒绝后仍可使用手动文件导入和目录授权。
- APP 进入前台、系统媒体库音频变化、存储挂载/移除以及 USB 设备变化时触发扫描。请求防抖、串行执行；关闭自动扫描会取消当前扫描。
- 手机媒体库按存储卷读取，排除系统标记的铃声、闹钟和通知音，生成可以直接交给 Media3 播放的 `content://` 地址。
- 未进入系统媒体库的 U 盘可通过“添加目录 / U盘”选择音乐目录，持久保存只读授权。随后递归扫描；缓存未变化文件的标签，避免每次重新读取。多个入口可识别同一媒体 URI 时去重。
- 添加目录和文件导入不复制整个音频到 APP，不上传音乐文件。文件读取、目录遍历和标签解析在 IO 线程进行。不可读文件计数提示；目录连接或授权失效有提示。
- 本地列表合并手动导入、扫描发现、APP 下载文件。操作区自动换行，提示最多两行，歌曲列表单独占用剩余空间。
- 移除导入/扫描记录保留原文件，并记住隐藏状态，防止自动扫描立即重新添加；“更多 → 重新显示已移除歌曲”可恢复扫描发现。APP 下载文件沿用原来的确认后删除逻辑。
- “更多 → 管理扫描目录”可以停止扫描某目录，保留原文件和既有单文件导入的权限；“音频权限设置”进入系统权限页面。

Android 对系统媒体库和任意目录的访问方式不同。首次 U 盘目录授权仍须通过系统选择器；无需用户填写 token 或文件路径。目录根选择范围由车机固件的系统文档提供器决定，不能保证每台车机都允许选择整个 U 盘根目录。

官方依据：[Android 媒体库与音频权限](https://developer.android.com/training/data-storage/shared/media)、[持久化目录访问](https://developer.android.com/training/data-storage/shared/documents-files)、[Reorderable 2.2.0](https://github.com/Calvin-LL/Reorderable/tree/v2.2.0)。
