# 星河音乐 CarMusic 开发设计与技术规格说明书

更新：2026-10-02。以确认的 `design/portrait-v1` HTML 和用户后续意见为产品依据。

## 产品与适配

服务于博越 L 等 ARM64 Android 竖屏车机，同时适配竖屏手机。原记录的车机屏幕为 1440×1920、Android 11；本轮连接的实际测试设备为 Redmi K20 Pro、Android 14、1080×2340，不能用手机测试替代实车验证。

最低 Android 8.0/API 26；当前 compile/target SDK 34；ARM64 构建。布局按 dp 和实际可用空间自适应，播放封面尺寸随页面空间调整。默认专辑封面，可选旋转黑胶。

## 页面与交互

- 启动进入首页，四个模块为正在播放、歌单列表、我的收藏、系统设置。自动播放默认关闭，可在设置开启。
- 日间、夜间、跟随系统三种主题；侧栏展开/收起箭头改变方向。窄屏选择菜单后自动收起侧栏。
- 左侧完整入口为首页、正在播放、歌单列表、我的收藏、系统设置、全网搜索、本地音乐、下载管理；播放队列由播放页按钮进入，不设置独立状态演示菜单；不再显示底部重复导航，统一从侧边栏进入。
- 首页按确认稿展示继续播放大卡、双列歌单/收藏入口、设置横条及真实最近听过。设置按七个分类组织，宽屏左侧分类，窄屏横向分类。
- 开屏覆盖整个屏幕并隐藏系统栏，星轨音乐 Logo，流动描边艺术字“一路星河，一路好歌。”，保留“为每一段旅程，留一首好歌。”。
- 正在播放页面：封面/黑胶、歌曲名与歌手、逐行歌词、进度条、时间、上一首/播放暂停/下一首、顺序/随机/单曲循环/列表循环、收藏红心、队列按钮。歌词滑动仅用于浏览，不改变播放进度；点击可见歌词行才跳转到对应时间。停止滑动后 2 秒内未点击，自动回到正在播放的歌词位置。
- 播放页通过右侧播放列表按钮打开当前队列；队列使用三横杠手柄长按上下拖动，不显示上移/下移箭头，支持移除和清空确认。随机模式重排可见队列，下一首按可见顺序播放。删除正在播放的曲目播放剩余曲目；删除最后一首停止播放。队列操作不删除真实歌单、收藏或文件。
- 歌单“播放全部”替换当前队列为该歌单；歌单、搜索结果、收藏和历史中点击单曲时，将该歌曲置于当前队列首位并播放，保留其余歌曲原顺序，不重复添加。队列内直接点击歌曲只切换播放，不改变手动排序。
- 移除界面倍速控制，启动恢复正常 1 倍速。播放模式图标直接点击循环切换顺序、随机、单曲循环、列表循环，不展开菜单；模式在左、播放列表入口在右。
- 通知栏播放控制默认开启，可在“车机与显示”关闭前台卡片；后台播放保留 Android 必需的媒体服务通知。通知提供上一首、播放/暂停、下一首，显示歌名和当前歌词。
- 歌单列表默认显示当前应用收藏，平台横向切换。账号关联且个人歌单非空时优先展示个人歌单，否则展示推荐；可手动切换个人/推荐及浏览分类。账号未关联、空数据和网络错误分别显示，成功歌单列表保留缓存。
- 我的收藏显示本应用的收藏音乐，可切换各平台账号的歌单。收藏为实心红心。
- 搜索统一入口位于首页、歌单和收藏页，播放和设置不放搜索。支持歌曲、歌单、专辑、分享链接和多平台选择；平台能力由引擎返回。
- 歌单/专辑详情从列表进入，不是一级菜单；无独立歌词展开菜单。顶部将播放全部、收藏外部歌单/专辑和多选放在同一个自动换行的操作区；不显示随机播放、加入队列、下载全部和默认顺序。下载所选、加入本地歌单、换源等集中在多选后显示；“加入本地歌单”添加选中歌曲，“收藏歌单”保存整张平台歌单入口。
- 本地歌单支持创建、编辑、删除、加入/移除歌曲。外部导入集合保存源平台和外部 ID，保留上游只读曲目规则。

## 设置与低频工具

保留上游全部 WebSettings 字段：下载元数据嵌入、下载到本地、目录、文件命名、提示时长、WebDAV 开关/地址/用户/密码/目录、悬浮歌词配置、网页/命令行分页数量、下载并发、自动检查更新、失效换源、播放自动缓存、更新仓库、GitHub 代理开关/地址、视频封面/音频/歌词/导出开关。

账号支持上游各源 Cookie，支持能力范围内的二维码登录/轮询及汽水短信验证。用户实际登录由用户本人授权，不预置账号、不伪造个人歌单。

低频入口包含本地音乐导入与移除、下载文件确认删除、下载历史分页与清空、重复文件分页与确认删除、索引重建、播放缓存清理、代理测试、查看上游更新、视频编辑。

视频编辑具有对应的封面/背景/音频文件选择器、本地音乐选择、LRC/TXT 导入与编辑、标题编辑、歌词显示开关、制作进度/取消和 MP4 保存选择器。支持 9:16、1:1、3:4、16:9 比例，720p/1080p，30fps、H.264/AAC；默认 9:16。背景可跟随封面、使用纯色或独立图片。画面预览与编码共用绘制逻辑。受上游 vg 配置开关控制。原生导入音频与本地下载音频可作为素材。

素材网络请求支持取消；远程封面限制 20 MiB，歌词限制 1 MiB，兼容 UTF-8/UTF-16 BOM。系统文档选择器导入、实际编码、系统保存窗口与最终 MP4 的音视频元数据已在独立测试包验证。下载保留上游元数据降级与 WebDAV 同步失败提示，明确区分本地文件保存与远程同步。

关于页面保留上游介绍，功能来源名称 GoMusicDll，链接 https://github.com/guohuiyuan/go-music-dl 。星河音乐自己的项目 URL 依用户要求空白。无气温、常驻在线和设计说明文案。

## 架构与持久化

Compose 原生前端通过 localhost HTTP 调用 Go Music DL 引擎，整个主界面不采用 WebView。媒体服务为 Media3 MediaSessionService + ExoPlayer，接收系统媒体控制和音频焦点。2GB LRU 播放缓存；完整缓存和已下载文件优先播放；本地引用无需流解析。失败音源可以自动换源，失败队列有界跳过；手动换源保留原收藏/队列身份。

正式包 com.carmusic.app，引擎仅监听 127.0.0.1:37777，路径 /music。独立自动化包 com.carmusic.app.smoke 使用端口 37779、独立存储，不能用正式包运行 Gradle connected 测试。Go 从 nativeLibraryDir 执行 libcarmusic.so，避免 Android W^X；FFmpeg、ffprobe、libc++ 同样打包为 native libraries。

设置与账号、本地歌单、下载记录使用上游 SQLite；主题/收藏/本地导入 URI/播放队列/当前曲目/进度/模式使用 Android SharedPreferences。SAF 音频导入申请持久读取授权，移除导入记录不删除原文件。队列和进度恢复不自动开始播放，除非用户开启自动播放。

原生 JSON 返回完整曲目列表，不受网页分页截断。Android 使用系统 CA；Go 自定义 Android 可用 DNS；网络请求可取消；引擎有启动等待和防重复启动处理。

## 构建与验证

使用 Java 17、Android SDK、Gradle wrapper、Go 1.25+。Go 交叉编译：GOOS=linux、GOARCH=arm64、CGO_ENABLED=0，输出 app/src/main/jniLibs/arm64-v8a/libcarmusic.so。

Android：`gradlew.bat :app:assembleDebug :app:testDebugUnitTest`。

真机自动化仅使用 `gradlew.bat :app:connectedSmokeAndroidTest`，测试结束时 Gradle 会卸载独立测试包，不能改成正式 debug 包测试。

测试记录与当前未验证项见 IMPLEMENTATION_STATUS.md。第三方来源与许可证见 THIRD_PARTY_NOTICES.md。旧规格已归档为 CarMusic_旧版规格_存档.md，旧版描述的动态响度归一化和实车方控 100% 验证不能视为当前已实现/已验证承诺。
