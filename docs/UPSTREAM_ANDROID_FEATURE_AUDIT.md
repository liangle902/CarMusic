# 原安卓版本功能对比与验收

基准：本地保留的上游 ARM64 APK `upstream-v1.1.1-arm64.apk`（包名 `com.musicdl.app.util`，版本 `1.0.0.389`），以及 `engine/upstream/desktop_app`、`internal/web/templates` 的实现。原版安卓通过 Gio WebView 加载上游页面，因此页面脚本、服务端 API 和安卓桥接均属于对比范围。

此表区分代码覆盖、测试通过与外部验证限制。对照上游源码逐项保留业务入口；界面按确认稿和用户后续要求调整。没有真实账号或车辆验证的项目不会记作已验证。

## 外部验证范围

QQ 正式包个人歌单已观察到成功加载。其他平台扫码最终授权、尤其汽水平台限流后的账号确认，需要平台实际签发会话；二维码可解码和轮询单元测试不代表登录成功。私人 WebDAV 服务器、长曲视频编码耗时及实车媒体按键/导航焦点尚未实测。原生配置、历史清空、维护等低频入口有代码覆盖及上游引擎测试，未逐个列为独立真机流程。
