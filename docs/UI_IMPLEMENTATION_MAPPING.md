# 确认稿与原生界面的分区对应

依据：`design/portrait-v1/index.html`、`app.js`、`styles.css` 及用户补充意见。

| 确认稿 | 原生实现 |
| --- | --- |
| 左栏 8 个可见页面，排除详情、歌词展开、队列、视频和状态演示 | 首页、正在播放、歌单列表、我的收藏、系统设置、全网搜索、本地音乐、下载管理；队列从播放页右侧按钮进入，视频从高级设置进入 |
| 侧栏左右收放箭头，随日夜主题切换 | 可收起并滚动，线条图标与确认稿同形；主题由系统/手动设置控制 |
| 首页继续播放封面大卡 | 恢复真实当前曲目、封面和进度；无记录时引导选择音乐，保持自动播放默认关闭 |
| 歌单/收藏双列入口、设置横条、最近听过 | NativeHome 同样的层级与排列；最近听过来自真实播放记录 |
| 统一侧边栏导航 | 已移除底部四项重复导航；四个主模块从侧边栏进入 |
| 播放封面与歌词并排，曲目信息和控制区在下方 | 自适应封面/黑胶与可滚动歌词并排，红心位于曲目信息右侧；队列按钮打开弹层，不在播放页堆叠队列 |
| 歌单平台标签、左侧个人/推荐、右侧封面网格 | NativeLibrary；本地收藏以歌单卡片展示；平台个人歌单非空时优先，否则推荐 |
| 歌单详情操作区随屏幕自适应 | 播放全部、收藏平台歌单、多选共用 FlowRow；取消重复下载、随机播放、加入队列及默认顺序入口，批量动作在多选后显示 |
| 收藏概览、播放全部、排序和歌曲行 | APP 收藏概览与实际数量；平台标签切换读取平台歌单，不伪造同步或合并收藏 |
| 设置七个分类 | 播放与显示、平台账号、常规、下载与存储、WebDAV 同步、高级选项、关于；宽屏左列，手机横向分类 |
| 下载完成/任务记录 | 下载管理独立页面，读取实际下载文件与分页记录，失败任务可重试 |
| 视频比例、标题、背景、歌词和导出清晰度 | 高级设置中的视频制作支持 9:16/1:1/3:4/16:9、标题编辑、封面/纯色/独立背景、歌词开关、本地音乐与文件音频、720p/1080p；预览与编码共用画面绘制 |
| 空白与异常状态不再是侧栏菜单 | 各业务页面继续显示自身实际的空数据与错误状态 |

原型的演示歌曲、示例账号与虚构推荐不会成为真实 APP 数据。最新正式包的首页、播放、队列、平台歌单、收藏和设置截图位于 `screenshots/`，README 已加入六图预览。
