# 原生实现状态

以 `design/portrait-v1` 确认稿和用户后续意见为依据。开发持续进行，以下区分已验证与待验证。

## 产品规则
- 默认进入首页，自动播放默认关闭；保留四个主要模块。
- 跟随系统/日间/夜间主题，侧栏可收起，收藏实心红心。
- 专辑封面默认，黑胶可选；歌词点击跳转；滑动只浏览，停止滑动 2 秒未点击自动回到当前歌词。
- 播放页通过队列按钮管理队列，队列不修改原歌单和文件。
- 平台个人歌单优先；未登录、请求错误、空列表区分，保留缓存。
- 所有低频功能集中在设置；保留上游配置和视频编辑入口。
- 无气温、无常驻在线；星轨 Logo、全屏艺术字开屏。
- 功能来源显示 GoMusicDll；自身 GitHub 链接已加入“关于”。
